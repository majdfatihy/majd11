أنشئ موقعك مجاناً على GitHub Pages!

لا تحتاج لخبرة برمجية. دع الذكاء الاصطناعي يكتب لك الكود، وارفع موقعك للعالم بثوانٍ معدودة.

كيف تصمم موقعك باستخدام الذكاء الاصطناعي؟ (شرح عملي)

يمكنك استخدام نماذج الذكاء الاصطناعي التالية لتوليد ملفات HTML, CSS, JS ورفعها فوراً:


  • Gemini (من جوجل): الأفضل في كتابة أكواد حديثة متوافقة مع SEO. اطلب منه: "اكتب لي كود HTML و CSS لصفحة شخصية بسيطة باللغة العربية".
  • ChatGPT: دقيق جداً في تصحيح الأخطاء. يمكنك أن تطلب منه بناء مكونات محددة مثل "نموذج اتصال" أو "شريط تنقل".
  • Claude: ممتاز في توليد الأكواد الطويلة والمعقدة بملف واحد متكامل (Single Page).
  • GitHub Copilot: إذا كنت تستخدم محرر VS Code، سيقوم باقتراح الأكواد وإكمالها أثناء برمجتك للموقع قبل رفعه مباشرة إلى مستودعك (Repository).

خطوات الرفع على غيت هاب:

  1. أنشئ حساباً مجانياً على GitHub.
  2. أنشئ مستودعاً (Repository) جديداً باسم: username.github.io.
  3. ارفع الملفات التي قام الـ AI بتوليدها (تأكد أن الصفحة الرئيسية باسم index.html).
  4. مبروك! موقعك الآن لايف ومجاني بالكامل.
